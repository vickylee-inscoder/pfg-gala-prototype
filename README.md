# PfG Charity Gala · donation page prototype

Mobile prototype of the Paws for Good Charity Gala (12 Nov) donation page that guests reach from table QR codes.

**Open on a phone:** https://vickylee-inscoder.github.io/pfg-gala-prototype/

Flow: choose one or more gifts → Give → Shopify native checkout (simulated) → Shopify thank-you page with a custom gala block (Checkout UI extension, simulated).

Final look: Daylight tone, PfG brand card colours, Figtree amounts. All figures are sample data; no payment is taken.
